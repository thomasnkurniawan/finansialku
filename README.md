# Finansialku 💰

An AI-powered personal and household finance tracker built with:

- ⚡️ Next.js (App Router)
- 🎨 Tailwind CSS + shadcn/ui
- 🔐 Supabase Auth & Database
- ✨ Future-ready AI integration

## Features

- Track individual & household income
- Auth with Supabase
- Clean, responsive UI with reusable components
- Easy to extend and scale for SaaS
